# 遊ぶ・自分の村人の手順（招待リンクだけ）

Google ログインは使いません。DM で「住みたい」と送った人に、その人専用のリンクが届きます。そのリンクを開いた端末で「自分の村人」として遊べます。

## しくみ

1. DM で「住みたい」→ いつもの入居（`docs/DMで入居する手順.md`）。
2. 返事を送る時（`node tools/dm.js done` → 受け口の `/dm/done`）に、受け口（Cloudflare の Worker）がその村人の印を作り、返事の文にリンクを入れます。リンクの形は `https://（サイト）/?me=<印>` です。
   - 印は 32 字のでたらめな文字です。KV には印のハッシュだけを置きます（`me:<ハッシュ>` → 村人、`mev:<村人>` → 今のハッシュ）。
   - 印は GitHub・公開リポジトリ・data/ には一度も出ません。作るのも確かめるのも受け口の中だけです。
   - もう一度 DM すると新しい印が届き、前の印は使えなくなります（別のスマホに移る時はこれ）。
3. リンクを開くと、その端末（localStorage の `town.me`）に印を覚えます。URL からは印を消し、「あなたは @○○ として島にいます」と出します。
4. メニューの「自分の村人」は、つながっていれば顔と名前になります。つながっていなければ DM 版の住み方の案内（`./?join=dm`）へ行きます。
5. 遊ぶ（`play.html`）：釣り・宝探し・おてつだい。結果と設定（鉱石：自分で持つ／倉庫に入れる）は、印をつけて受け口に送ります。受け口が印を確かめて KV に記録し、1 日の回数も数えます。
6. 「この端末から出る」（自分の村人のページ）を押すと、その端末の印を忘れます。

## 本番で要ること

### 1. 受け口（tools/webhook/worker.mjs）を出し直す

DM の入居で使っている Worker に、新しい `worker.mjs` をそのまま貼り直して出し直します。

Worker の設定（Settings → Variables）：

| 名前 | 中身 |
| --- | --- |
| `TOWN_KV` | もう付いている KV（そのまま） |
| `DM_QUEUE_TOKEN` | もう入っている合言葉（そのまま。`/play/pull` もこれで読む） |
| `SITE_ORIGIN` | サイトの元の URL。例 `https://hajimarijima.github.io`（最後の / はなし）。リンクの先と、サイトから読める元（CORS）に使う |
| `ME_LINKS` | なくてよい。`off` にすると、返事にリンクを入れない（止めたい時だけ） |

### 2. サイトの config.json

`data/config.json` の `play.apiUrl` に Worker の URL を入れます（例 `https://town-hook.xxxx.workers.dev`）。

- 空のあいだは「準備中」と出て、受け口には何も送りません（見本 `?demo-me=1` は動きます）。
- `fishPerDay`（釣り 1 日の回数）・`chorePerDay`（おてつだい 1 日の回数）・`choreGoal`（みんなの目標）もここで変えます。受け口もこの値を読んで数えます（5 分おぼえる）。
- DM の入居そのもの（`config.dm.enabled: true`）が動いていることが前提です。

### 3. 返事の文

`config.dm.messages` の文に `{me}` と書くと、そこにリンクが入ります。書かなければ、文の最後の行に「あなた専用のリンク…→ URL」が足されます。リンクを作らない時（`ME_LINKS=off` など）は `{me}` は消えます。

### 4. 遊びの記録を取り出す（あとで sim 側が使う）

```
node tools/play.js pull [--days 3]
```

`DM_QUEUE_URL`・`DM_QUEUE_TOKEN`（DM と同じ）で受け口の `/play/pull` を読み、`data/inbox/play.json` に置きます（inbox は公開しません）。join.yml に足す時は、`node tools/dm.js pull` の次に同じ env で 1 行足します。sim・年表への反映は別の担当が行います。

中身：設定（村人ごとの oreMode）・日ごとの記録（fish・chores・treasure・catches）・みんなのおてつだいの合計・宝箱のいちばん乗り。

## 見本（何も保存しない・受け口にも送らない）

- `play.html?demo-me=1` … つながった状態で遊べる（`&tab=treasure`・`&tab=chore` で宝探し・おてつだい）
- `me.html?demo-me=1` … 自分の村人のページ（`&k=村人の key` で人を選べる）
- `index.html?demo-me=1&me=x` … リンクを開いた時の「あなたは…」

## 気をつけること

- KV の書きこみは無料だと 1 日 1000 回まで。遊び 1 回で 1〜2 回書きます。1 日の記録は 8 日、宝の記録は 40 日で消えます。
- 釣れた魚と大きさはサイト側で決めて送ります。受け口は config の範囲の中かだけを確かめます（ずるはふせぎきれません。回数だけは受け口が守ります）。
- KV は足し算を守らないので、同じ時に押した人がいると、みんなの合計や「いちばん乗り」がまれにずれることがあります。
- リンクを人に教えると、その人も同じ村人として遊べます。困った時はもう一度 DM すれば前のリンクは使えなくなります。
- Firebase（Google ログイン）と `firestore.rules`・`js/auth.js` はもう使いません。`config.firebase.enabled` は false のままにしておきます。
