# インスタに使う文章（下書き）

島の名前は「はじまり島」に決まりました。参加のことばは「住みたい」です（「参加したい」も今までどおり受け付けます）。

---

## プロフィール（概要欄）
```
はじまり島の町づくり🏝️
村人0人の島に、みんなで町を作ります

✅ コメントに「住みたい」で村人になれる
⛏️ 選んだ道具で役割が決まる（例：住みたい ピッケル）
📩 住んだら DM でお知らせ
🗳️ 毎日 A・B・C の選択で町の進み方が決まる

町の様子はいつでもここで見られます👇
```
（リンク欄に https://hajimarijima.github.io/ を入れる）

---

## パート1（0日目）の投稿文
```
【パート1】0日目｜村人0人の島

ここに町を作ります。
でも、まだ村人は0人。

コメントに「住みたい」と書いた人が、
次の動画から村人として島に住みます🏠

⛏️ 道具も書くと、その道具で始まります
 ・住みたい ピッケル → 岩を掘る
 ・住みたい 斧 → 木を切る
 ・住みたい 釣り → 魚を釣る
 ・住みたい くわ → 畑を作る

📩 住んだ人には、DM でお知らせします
（村人の名前・自分のページの見方を送ります）

明日は1日目。
みんなで A・B・C から選びます。

#町づくり #村づくり #参加型 #ブロック #ドット絵 #箱庭 #シミュレーション #毎日投稿
```

## パート1の固定コメント
```
👇ここに「住みたい」とコメントしてね
道具も書くと、その道具を持って島に来ます（ピッケル／斧／釣り／くわ）
選んだ道具で役割が決まります（ピッケル＝採掘、斧＝木こり、釣り＝漁師、くわ＝農家）
住んだ人には DM でお知らせします📩
名前は動画には出ません
```

```
【パート〇】〇日目｜村人〇人

（その日の出来事を1〜2行）
例：はじめての木を切った。チェストに原木が3つ入った。

🗳️ 今日の選択
A：〇〇
B：〇〇
C：〇〇
コメントに A・B・C で答えてね（〇時まで）

🆕 今日から住んだ村人：〇人
まだの人は「住みたい」で村人になれます

#町づくり #村づくり #参加型 #ブロック #ドット絵 #箱庭 #毎日投稿
```

## 1日目からの固定コメント
```
🗳️ A・B・C をコメントで選んでね（〇時まで）
🏠 新しく住みたい人は「住みたい」とコメント
```

## メモ
- 名前は動画に出さない決まりなので、固定コメントにも書いておく。
- 「マインクラフト」「マイクラ」は他社の商標なので、アカウント名・島の名前には入れない。投稿文やハッシュタグにも入れない方が安全。
- 投票の締め切り時間は、毎朝の自動更新（6時）に合わせて「前の日の24時まで」がおすすめ。
