# インスタに使う文章（下書き）

島の名前はまだ決まっていなかったので、案を出しています。決まったら【島の名前】の所を差し替えます。

## 島の名前の案
1. **はじまり島**（おすすめ。サブ島ができても「はじまり島」がメインだと分かる）
2. **ゼロ島**（村人 0 人から始まる企画に合う）
3. **つみき島**（ブロックの見た目に合う、やわらかい名前）
4. **コメント島**（コメントで育つことがすぐ伝わる）

---

## プロフィール（概要欄）
```
【島の名前】の町づくり🏝️
村人0人の島に、みんなで町を作ります

✅ コメントに「参加したい」で村人になれる
⛏️ 道具も書くとその道具で始まる（例：参加したい ピッケル）
🗳️ 毎日 A・B・C の選択で町の進み方が決まる

町の様子はいつでもここで見られます👇
```
（リンク欄に https://winter1214.github.io/town/ を入れる）

---

## パート1（0日目）の投稿文
```
【パート1】0日目｜村人0人の島

ここに町を作ります。
でも、まだ村人は0人。

コメントに「参加したい」と書いた人が、
次の動画から村人として島に住みます🏠

⛏️ 道具も書くと、その道具で始まります
 ・参加したい ピッケル → 岩を掘る
 ・参加したい 斧 → 木を切る
 ・参加したい 釣り → 魚を釣る
 ・参加したい くわ → 畑を作る

明日は1日目。
みんなで A・B・C から選びます。

#町づくり #村づくり #参加型 #ブロック #ドット絵 #箱庭 #シミュレーション #毎日投稿
```

## パート1の固定コメント
```
👇ここに「参加したい」とコメントしてね
道具も書くと、その道具を持って島に来ます（ピッケル／斧／釣り／くわ）
名前は動画には出ません
```

---

## 1日目からの投稿文のひな形
```
【パート〇】〇日目｜村人〇人

（その日の出来事を1〜2行）
例：はじめての木を切った。チェストに原木が3つ入った。

🗳️ 今日の選択
A：〇〇
B：〇〇
C：〇〇
コメントに A・B・C で答えてね（〇時まで）

🆕 今日から住んだ村人：〇人
まだの人は「参加したい」で村人になれます

#町づくり #村づくり #参加型 #ブロック #ドット絵 #箱庭 #毎日投稿
```

## 1日目からの固定コメント
```
🗳️ A・B・C をコメントで選んでね（〇時まで）
🏠 新しく住みたい人は「参加したい」
```

## メモ
- 名前は動画に出さない決まりなので、固定コメントにも書いておく。
- 「マインクラフト」「マイクラ」は他社の商標なので、アカウント名・島の名前には入れない。投稿文やハッシュタグにも入れない方が安全。
- 投票の締め切り時間は、毎朝の自動更新（6時）に合わせて「前の日の24時まで」がおすすめ。
