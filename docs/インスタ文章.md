決まり（2026-11-26 から）：
- フォローして「住みたい」とコメントすると、**すぐ**（15 分ほどで）島に住める。次の朝を待たない。

## 拠点の場所の投票（0日目）の投稿文
投稿したら、下の「投稿の URL を町に教える（スマホで）」で、この投稿の URL を「投票の投稿の URL」に貼る（何もしないと Secrets の `IG_VOTE_MEDIA`、それもなければ いちばん新しい投稿のコメントを数える）。
候補の名前を変えた時（`data/config.json` の `baseVote.candidates` の `name`）は、ここの A・B・C の名前も同じにする。
```
【拠点はどこにする？】はじまり島 0日目

町のチェストとたき火を置く「拠点」の場所を、みんなで決めます🗳️
家や建物は、拠点のまわりに建っていきます。

A 浜辺の近く 🏖️ 島の南のはし。海が目の前・釣りにも近い
B 池のそば 🎣 島の西。池のすぐそば、となりは広い野原
C 森の入口 🌲 島の北。木がたくさん。北の島への橋にも近い

コメントに A・B・C のどれか1つを書いてね
（「浜辺」「池」「森」でもOK・1人1票・書き直したら最後のコメント）

1日目が始まる朝に決まります。
いまの票は、プロフィールのリンクの町の画面で見られます👀

#町づくり #村づくり #島づくり #参加型 #フォロワー参加型 #ブロック #ドット絵 #箱庭 #投票
```

## 拠点が決まった時のお知らせ
```
📣 拠点は「〇 〇〇〇」に決まりました！（A 〇票・B 〇票・C 〇票）
ここにチェストとたき火を置いて、まわりに家や建物を建てていきます🏠
次は「何を建てる？」の投票です。
```
※ 拠点が決まったら、次の「何を建てる？」の投稿を作って、その URL を下の手順で「投票の投稿の URL」に貼る（同じ投稿のままだと、拠点の投票の A・B・C が「何を建てる？」の票にまざることがある）。

## 投稿の URL を町に教える（スマホで）
1. インスタで投稿の「…」→「リンクをコピー」。
2. GitHub アプリ（またはスマホのブラウザで github.com）でリポジトリを開く →「Actions」→「投稿の URL を変える」。
3. 「Run workflow」を押し、コピーした URL を貼る。
   - 投票の投稿なら「投票の投稿の URL」、「住みたい」を集める投稿なら「住みたいの投稿の URL」。
   - 住みたいの投稿は足していくので、前の投稿の「住みたい」も受け付けつづける。
4. もう一度「Run workflow」を押す。緑のチェックになれば終わり（数分で、投票のページのボタンも新しい投稿へのリンクになる）。
- 赤くなったら、貼った物がインスタの投稿の URL でない。`https://www.instagram.com/p/…` か `/reel/…` の形か見る。
- 消したい時は、URL の代わりに「消す」と書く（Secrets の ID に戻る）。

## メモ
- 村人の頭の上には、サイトでも動画でもインスタの名前（@名前）が出る。出したくない人は hidden（Secrets の TOWN_HIDDEN）に入れると、あだ名になる。
- 「マインクラフト」「マイクラ」は他社の商標なので、アカウント名・島の名前・投稿文・ハッシュタグには入れない。
- 投票の締め切り時間は、毎朝の自動更新（6時）に合わせて「前の日の24時まで」がおすすめ。
- 1日目を始める方法は README の「町を始める日」を見る（config.json の startAt、または Actions の daily を start で動かす）。
